# ProjectFlow Desktop

Downloads and automatic updates for **ProjectFlow Desktop** (macOS and Windows), the desktop app for
[ProjectFlow](https://getprojectflow.com). This repository contains release builds only — no source code.

## Download

- **macOS** (Apple silicon and Intel, signed and notarized):
  [ProjectFlow-mac.dmg](https://github.com/ChristophLabestin/projectflow-desktop/releases/latest/download/ProjectFlow-mac.dmg)
- **Windows 10/11**:
  [ProjectFlow-Setup.exe](https://github.com/ChristophLabestin/projectflow-desktop/releases/latest/download/ProjectFlow-Setup.exe)

Or use the download page: <https://app.getprojectflow.com/download>. All versions: [Releases](https://github.com/ChristophLabestin/projectflow-desktop/releases).

Installed apps update themselves from this repository's releases.
